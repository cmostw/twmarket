## Historical and current data

`history`, `index_history` and `exchange_rates` accept date ranges. Statements and revenue use year, quarter or month to select a period.

Security directories, active contracts, margins and shareholding distribution provide the currently published records. Follow the API links above for parameters and return types.

## Convert results

[DataFrame conversion](/en/docs/how-to/dataframes) supports pandas and Polars. Flat models become rows and statements become account long tables.
