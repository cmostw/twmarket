## Values and dates

Prices and monetary values use `Decimal`. Missing values use `None`. Read each model's `volume_unit`, `amount_unit` or `unit` for units.

Percentage fields retain percent units. For example, `20.25` means 20.25%.

`SourceInfo` records the source, URL and UTC retrieval time. Model date fields identify trading dates and reporting periods.

## `BatchResult`

An original batch input with either its data or its exception.

Batch query results retain input order and duplicate entries.

### Fields

```python
instrument: str | Contract
data: T | None
error: Exception | None
```

### `ok`

```python
def ok() -> bool: ...
```

Whether this batch entry completed without an exception.

## `SourceInfo`

Response provenance.

received_at is the timezone-aware UTC retrieval time, not a trading date.

### Fields

```python
provider: str
url: str
received_at: datetime
```

## `EquityDaily`

Daily security prices and turnover with explicit source units.

TWSE uses shares/TWD.

TPEx uses lots/thousand_TWD. Missing values are None.
change_basis_reset marks a source reset of the price-change comparison basis.

### Fields

```python
symbol: str
date: date
open: Decimal | None
high: Decimal | None
low: Decimal | None
close: Decimal | None
volume: int | None
amount: Decimal | None
volume_unit: Literal['shares', 'lots']
amount_unit: Literal['TWD', 'thousand_TWD']
source: SourceInfo
change: Decimal | None = None
transactions: int | None = None
raw_change: str | None = None
change_basis_reset: bool = False
```

## `Contract`

Exact futures or options identity.

expiry retains month, weekly series or spread periods. Options include strike
and right.

mis_symbol and expires_on are populated from official metadata.

### Fields

```python
product: str
expiry: str
kind: InstrumentKind = 'future'
strike: Decimal | None = None
right: Literal['call', 'put'] | None = None
mis_symbol: str | None = None
expires_on: date | None = None
```

### `expiry_month`

```python
def expiry_month() -> str: ...
```

Return the first delivery month.

expiry retains week/spread information.

### `legs`

```python
def legs() -> tuple['Contract', ...]: ...
```

Return source spread legs, or an empty tuple for an outright contract.
