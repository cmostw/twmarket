## `to_pandas`

```python
def to_pandas(data: object, *, model: type[object] | None=None, price_type: PriceType='decimal') -> pd.DataFrame: ...
```

Convert records, a financial statement or batch results to a pandas DataFrame.

Args:
    data: One record or an iterable of records of the same model.
    model: Schema for empty/all-failed inputs.

empty inputs default to EquityDaily.
    price_type: decimal preserves Decimal objects.

float converts Decimal values.

Financial statements expand into account/period/measure rows. Batch frames
include requested_* and error columns. Order books and tick bands are omitted.
Requires twmarket[pandas].

invalid or mixed models raise TypeError.

Financial statements expand into account/period/measure rows. Batch frames

Requires twmarket[polars].

decimals exceeding precision 38 raise ValueError.

Return bid/ask rows with side, level, price and size columns.

Prices retain Decimal.
