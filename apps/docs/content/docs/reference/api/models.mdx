## `BatchResult`

保存原始批次輸入、資料或例外；批次保留順序與重複輸入.

### 欄位

```python
instrument: str | Contract
data: T | None
error: Exception | None
```

### `ok`

```python
def ok() -> bool: ...
```

回傳批次是否沒有例外.

## `SourceInfo`

記錄來源、端點及 UTC 取得時間；取得時間與交易日分開.

### 欄位

```python
provider: str
url: str
received_at: datetime
```

## `EquityDaily`

保存證券日行情與來源單位；TWSE 為股／元，TPEx 為張／千元.

### 欄位

```python

low: Decimal | None
close: Decimal | None
volume: int | None

source: SourceInfo
change: Decimal | None = None
transactions: int | None = None
raw_change: str | None = None
change_basis_reset: bool = False
```

## `Contract`

標識期貨或選擇權的商品、到期月份／週別、價差、履約價與買賣權.

### 欄位

```python
product: str
expiry: str
kind: InstrumentKind = 'future'
strike: Decimal | None = None
right: Literal['call', 'put'] | None = None
mis_symbol: str | None = None
expires_on: date | None = None
```

### `expiry_month`

```python
def expiry_month() -> str: ...
```

回傳第一個交割月份；expiry 保留週別與價差期間.

### `legs`

```python
def legs() -> tuple['Contract', ...]: ...
```

回傳來源價差兩腿期間；單一契約回傳空 tuple.

```python
low: Decimal | None
volume: int | None

quoted_at: datetime | None
source: SourceInfo
session: Session | None = None
source_date: date | None = None
status: str | None = None
contract: Contract | None = None
stale: bool = False
```
