## `Taifex`

查詢期交所契約、規格、保證金及行情。

### `daily`

```python
def daily(*, kind: InstrumentKind='future', product: str | None=None) -> list[DerivativeDaily]: ...
```

取得來源目前公布的日行情。

kind 選期貨／選擇權，product 可篩選商品。

### `contracts`

```python
def contracts(*, product: str, kind: InstrumentKind='future', expiry: str | None=None, session: Session='regular') -> list[Contract]: ...
```

依 product、kind、session 取得有效契約。

expiry 可篩選完整到期期間。

### `history`

```python
def history(contract: Contract, *, start: date, end: date, session: Session | None=None) -> list[DerivativeDaily]: ...
```

回傳含起訖兩日的歷史資料。

無符合資料時回傳空清單。

### `quote`

```python
def quote(contract: Contract | str, *, session: Session | None=None) -> Quote: ...
```

取得最新報價。

價格缺值為 None，查無快照時拋出 NoDataError.

### `resolve`

```python
def resolve(contract: Contract, *, session: Session='regular') -> Contract: ...
```

依官方有效期間核對 MIS ID 及到期日。

過期契約拋出 NoDataError.

### `products`

```python
def products(*, kind: InstrumentKind='future') -> list[DerivativeProduct]: ...
```

取得最新期貨或選擇權商品目錄、規格入口與乘數來源。

### `specification`

```python
def specification(product: str, *, kind: InstrumentKind='future') -> ContractSpecification: ...
```

取得商品乘數、幣別、交割方式與 tick 級距。

缺值為 None.

### `margins`

```python
def margins(*, category: MarginCategory='index', product: str | None=None) -> list[MarginRequirement]: ...
```

依 category 與選用 product 查最新保證金，保留金額或百分數單位。

### `quote_many`

```python
def quote_many(contracts: Iterable[Contract | str], *, session: Session | None=None) -> list[BatchResult[Quote]]: ...
```

逐筆回傳 BatchResult，保留輸入順序、重複輸入及個別錯誤。
