## `CBC`

查詢央行匯率並保留來源幣別配對方向。

### `exchange_rates`

```python
def exchange_rates(*, start: date, end: date, currency: str | None=None) -> list[ExchangeRate]: ...
```

查詢含起訖兩日的匯率。

currency 可篩選任一側幣別，維持來源方向。

## `AsyncCBC`

以 await 查詢央行匯率並保留來源幣別配對方向。

### `exchange_rates`

```python
async def exchange_rates(*, start: date, end: date, currency: str | None=None) -> list[ExchangeRate]: ...
```

查詢含起訖兩日的匯率。

currency 可篩選任一側幣別，維持來源方向。
