title: "TWSE / TPEx"
---

## `StockMarket`

查詢 TWSE 或 TPEx 的證券、指數與交易狀態。

### `history`

```python
def history(code: str, *, start: date, end: date) -> list[EquityDaily]: ...
```

回傳含起訖兩日的歷史資料。

無符合資料時回傳空清單。

### `quote`

```python
def quote(code: str) -> Quote: ...
```

取得最新報價。

價格缺值為 None，查無快照時拋出 NoDataError.

### `instruments`

```python
def instruments(*, category: str | None=None) -> list[Instrument]: ...
```

取得最新 ISIN 目錄。

category 使用來源分類名稱。

### `index_history`

```python
def index_history(*, start: date, end: date) -> list[IndexDaily]: ...
```

回傳含起訖兩日的每日指數 OHLC，依日期排序。

### `indices`

```python
def indices(*, day: date | None=None) -> list[IndexClose]: ...
```

取得價格／報酬指數收盤板。

day 省略時查來源最新公布資料。

### `ex_rights`

```python
def ex_rights(*, start: date, end: date, code: str | None=None) -> list[ExRight]: ...
```

依含起訖兩日的日期區間查詢歷史除權息。

code 可篩選證券。

### `ex_rights_schedule`

```python
def ex_rights_schedule(*, code: str | None=None) -> list[ExRightSchedule]: ...
```

取得最新除權息預告。

code 可篩選證券，未公告值為 None.

### `trading_restrictions`

```python
def trading_restrictions(*, kind: RestrictionKind='attention', code: str | None=None) -> list[TradingRestriction]: ...
```

依 kind 查詢注意、處置或最新暫停資料。

code 可篩選證券。

### `trading_status`

```python
def trading_status(*, code: str | None=None) -> list[TradingStatus]: ...
```

取得最新交易方式及狀態。

來源無發布日期時為 None.

### `quote_many`

```python
def quote_many(codes: Iterable[str]) -> list[BatchResult[Quote]]: ...
```

逐筆回傳 BatchResult，保留輸入順序、重複輸入及個別錯誤。
