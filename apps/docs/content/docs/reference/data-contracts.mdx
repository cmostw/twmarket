`Client` 與 `AsyncClient` 提供同名查詢方法。非同步方法使用 `await`。

| 資料 | 入口 | 方法 |
| --- | --- | --- |
| [上市、上櫃](/docs/reference/api/twse-tpex) | `twse / tpex` | `instruments`, `history`, `quote`, `quote_many`, `index_history`, `indices`, `ex_rights`, `ex_rights_schedule`, `trading_restrictions`, `trading_status` |
| [興櫃](/docs/reference/api/esb) | `esb` | `instruments`, `history`, `quote`, `quote_many`, `trading_restrictions` |
| [期貨、選擇權](/docs/reference/api/taifex) | `taifex` | `products`, `specification`, `margins`, `contracts`, `resolve`, `daily`, `history`, `quote`, `quote_many`, `stream` |
| [公司財務](/docs/reference/api/mops) | `mops` | `income_statement`, `balance_sheet`, `cash_flow_statement`, `revenue`, `dividends` |
| [股權分布](/docs/reference/api/tdcc) | `tdcc` | `distribution` |
| [景氣指標](/docs/reference/api/ndc) | `ndc` | `pmi`, `indicators` |
| [匯率](/docs/reference/api/cbc) | `cbc` | `exchange_rates` |

## 歷史與最新資料

`history`、`index_history`、`exchange_rates` 接受起訖日期。財報與營收使用年度、季度或月份選取期間。

證券目錄、有效契約、保證金及股權分布提供來源目前公布的資料。各方法的參數與回傳型別見上表的 API 連結。

## 轉換結果

[DataFrame 轉換](/docs/how-to/dataframes) 支援 pandas 與 Polars。平面模型轉成資料列，財報轉成科目長表。
