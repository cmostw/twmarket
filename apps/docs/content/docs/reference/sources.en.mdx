description: "Official sources used by each query namespace."
---

| Source | Interface | Data |
| --- | --- | --- |
| TWSE / TPEx | ISIN directories, official JSON/OpenAPI and TWSE MIS | Securities, history, indices, corporate actions, trading restrictions and quotes |
| Emerging stocks | ISIN, TPEx daily records and recommending-broker XML | Directory, daily history, quotes and restrictions |
| TAIFEX | OpenAPI, historical CSV, product pages and MIS | Futures/options history, contracts, specifications, margins and quotes |
| MOPS | Market Observation Post System | Balance sheets, income statements and cash-flow statements |
| MOPS | Market Observation Post System | Monthly revenue and dividends |
| TDCC | TDCC open data | Shareholding brackets in CSV |
| NDC | Official PMI/NMI CSV and business-cycle ZIP | Monthly observations, business-cycle signals and indicators |
| CBC | CBC exchange-rate data | Exchange-rate JSON |
