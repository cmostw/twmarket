需要 Python 3.11 以上與網路連線。以下範例查詢台積電的每日行情。

## 安裝

依套件管理工具選擇安裝指令：

```sh
pip install twmarket
# 可用延伸：stream、pandas、polars
```

```sh
uv add twmarket
# 可用延伸：stream、pandas、polars
```

## 查詢股票

將以下程式存成 `query.py`，執行 `python query.py`：

```python
from datetime import date
from twmarket import Client

with Client() as market:
    rows = market.twse.history(
        "2330", start=date(2026, 9, 1), end=date(2026, 9, 30)
    )

for row in rows:
    print(row.date, row.close, row.volume)
```

執行後，每列顯示交易日、收盤價與成交股數。

`history` 回傳每日行情清單。價格型別為 `Decimal`，缺值為 `None`。`with` 區塊結束時關閉連線。
