Python 3.11 or later and an internet connection are required. This example queries daily TSMC prices.

## Install

Installation commands by package manager:

```sh
pip install twmarket
# Available extras: stream, pandas, polars
```

```sh
uv add twmarket
# Available extras: stream, pandas, polars
```

## Query equities

Save this program as `query.py` and run `python query.py`:

```python
from datetime import date
from twmarket import Client

with Client() as market:
    rows = market.twse.history(
        "2330", start=date(2026, 9, 1), end=date(2026, 9, 30)
    )

for row in rows:
    print(row.date, row.close, row.volume)
```

Each output row shows the trading date, closing price and traded shares.

`history` returns a list of daily records. Prices use `Decimal` and missing values use `None`. Leaving the `with` block closes connections.
