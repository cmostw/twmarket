title: "Convert to DataFrames"
description: "Convert to DataFrames"
---

First [install the pandas or polars extras](/en/docs/how-to/installation).

```python
from twmarket import Client
from twmarket.integrations import to_pandas, to_polars

with Client() as market:
    statement = market.mops.income_statement("2330", year=2026, quarter=2)
    revenue = market.mops.revenue("2330", year=2026, month=8)

accounts = to_polars(statement)
monthly_revenue = to_pandas(revenue)
print(accounts.head())
print(monthly_revenue.head())
```

Conversions preserve `Decimal` by default. Set `price_type="float"` to convert numeric values to floats.

Financial statements expand into account, period and measure rows. Values retain their source units. Missing units are `None`.
