執行以下完整程式取得資料模型。數值與資料可用性依來源而變。

```python
from datetime import date
from twmarket import Client

with Client() as market:
    pmi = market.ndc.pmi(start=date(2026, 1, 1), end=date(2026, 9, 30))
    rates = market.cbc.exchange_rates(
        start=date(2026, 9, 1), end=date(2026, 9, 30), currency="USD"
    )

for row in pmi:
    print(row.period, row.series, row.value, row.text)
for row in rates:
    print(row.date, row.numerator, row.denominator, row.rate)
```

[NDC](/docs/reference/api/ndc) · [CBC](/docs/reference/api/cbc)

## 選擇系列與讀取結果

`pmi` 同時回傳 PMI 與 NMI，以 `series` 辨認系列，`period` 為觀測月份首日。景氣資料使用 `indicators(start=..., end=..., table="signal")`；`table` 可選 `signal`、`signal_components`、`leading`、`coincident`、`lagging`。數值在 `value`，燈號文字在 `text`。

`exchange_rates` 的日期範圍包含起訖兩日，`currency` 可省略，指定時匹配來源配對的任一側。讀取 `numerator`／`denominator` 判斷方向，不能只憑 `currency="USD"` 假設報價方向。
