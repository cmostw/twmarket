執行以下完整程式取得資料模型。數值與資料可用性依來源而變。

```python
from twmarket import Client

with Client() as market:
    statement = market.mops.income_statement("2330", year=2026, quarter=2)
    revenue = market.mops.revenue("2330", year=2026, month=8)
    distribution = market.tdcc.distribution("2330")

for value in statement.rows:
    print(value.account, value.period_end, value.measure, value.value, value.unit)
print(revenue.year, revenue.month, revenue.current, revenue.unit)
for bracket in distribution:
    print(bracket.date, bracket.level, bracket.people, bracket.shares, bracket.percentage)
```

[MOPS](/docs/reference/api/mops) · [TDCC](/docs/reference/api/tdcc)

## 選擇資料與期間

- `income_statement`、`balance_sheet`、`cash_flow_statement` 查三大財報；`year` 使用西元，`quarter` 為 1–4，兩者同時指定或同時省略查最新。
- `revenue` 的 `year`、`month` 同時指定，或同時省略查最新；回傳單筆 `Revenue`，不是清單。
- `dividends` 回傳股利決議清單；`distribution` 回傳 TDCC 最新公布的持股分級清單。

## 讀取結果

財報的 `rows` 是科目／期間／衡量類型的長表，同一科目可能有多列。依 `account`、`period_end` 與 `measure` 選取所需數值；`measure` 區分金額與百分數。不要將所有列相加。營收 `current` 為當月值，`cumulative` 為累計值，`change_percent` 保留百分數。

持股分級 `level` 為來源級距；16、17 分別為調整與總計，彙總時不可再將總計重複加總。單位與缺值見 [資料模型](/docs/reference/api/models)。
