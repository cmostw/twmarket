## 上市與上櫃

`market.twse` 查上市證券，`market.tpex` 查上櫃證券。`history(code, start=..., end=...)` 回傳每日資料，`quote(code)` 回傳單筆報價。代號使用字串以保留前導零。

```python
from datetime import date
from twmarket import Client

with Client() as market:
    rows = market.twse.history(
        "2330", start=date(2026, 9, 1), end=date(2026, 9, 30)
    )
    quote = market.tpex.quote("6488")

for row in rows:
    print(row.date, row.close, row.volume, row.volume_unit)
print(quote.last, quote.quoted_at)
for bid in quote.bids:
    print(bid.level, bid.price, bid.size)
```

每日資料的 `close` 是收盤價；報價的 `last` 是最新成交價，`bids`／`asks` 為買賣檔。缺值為 `None`。TWSE 歷史量／額為股／元，TPEx 為張／千元；以 `volume_unit`、`amount_unit` 判讀。

## 興櫃

興櫃使用 `market.esb`。以下從官方目錄選取代號，再取得成交統計與推薦券商報價：

```python
from twmarket import Client

with Client() as market:
    instruments = market.esb.instruments()
    if instruments:
        quote = market.esb.quote(instruments[0].symbol)
        print(quote.symbol, quote.last, quote.weighted_average)
        for broker in quote.broker_quotes:
            print(broker.broker, broker.bid, broker.ask)
```

`weighted_average` 是加權均價；`broker_quotes` 為個別推薦券商報價，不是集中市場五檔。`esb.history` 回傳 `EmergingDaily`，沒有一般股票的開收盤欄位。
