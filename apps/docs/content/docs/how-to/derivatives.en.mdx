```python
from twmarket import Client

with Client() as market:
    contracts = market.taifex.contracts(product="TX")
    if contracts:
        quote = market.taifex.quote(contracts[0])
        print(quote.contract, quote.last, quote.quoted_at)
    else:
        print("No active contracts")
```

[TAIFEX](/en/docs/reference/api/taifex)

## Select a contract

| Parameter | Selection |
| --- | --- |
| `product` | Official product code, such as `"TX"` |
| `kind` | `"future"` (default) or `"option"` |
| `expiry` | Exact delivery period |

Use `products(kind="future")` or `products(kind="option")` to list products.

Product codes identify a product family. Contracts specify a delivery period. Options also specify strike and right.

`resolve(contract, session=...)` verifies the contract's active quote identifier and expiration date.

Filter options by the returned contracts' `strike` and `right` fields.

The example selects the first listed contract. Filter the required contract and pass its complete `Contract` to `quote` or `history`.

## Query daily history

Call `history(contract, start=..., end=..., session=...)` with the selected contract and date range.

| `session` | Records |
| --- | --- |
| `"regular"` | Regular session |
| `"after_hours"` | After-hours session |
| Omitted | Both sessions |

Read `date` and `session` together. `last` is the last trade and `settlement` is the settlement price.

An after-hours trading date can differ from the calendar date of the trade timestamp.
