```python
from twmarket import Client

with Client() as market:
    contracts = market.taifex.contracts(product="TX")
    if contracts:
        quote = market.taifex.quote(contracts[0])
        print(quote.contract, quote.last, quote.quoted_at)
    else:
        print("No active contracts")
```

[TAIFEX](/docs/reference/api/taifex)

## 選擇契約

| 參數 | 選擇方式 |
| --- | --- |
| `product` | 官方商品代碼，例如 `"TX"` |
| `kind` | `"future"`（預設）或 `"option"` |
| `expiry` | 指定到期期間 |

以 `products(kind="future")` 或 `products(kind="option")` 查商品目錄。

商品代碼表示一類商品，契約以到期期間區分。選擇權另有履約價與買賣權。

`resolve(contract, session=...)` 核對契約的有效報價識別碼與到期日。

選擇權可依回傳契約的 `strike` 與 `right` 欄位篩選履約價與買賣權。

範例取目錄第一筆契約。依需求篩選契約後，將完整 `Contract` 傳入 `quote` 或 `history`。

## 查詢每日行情

呼叫 `history(contract, start=..., end=..., session=...)`，指定契約與日期範圍。

| `session` | 資料 |
| --- | --- |
| `"regular"` | 一般盤 |
| `"after_hours"` | 夜盤 |
| 省略 | 兩種時段 |

以 `date` 和 `session` 判讀交易日與時段。`last` 是最新成交價，`settlement` 是結算價。

夜盤的交易日可能與實際成交時間的日曆日期不同。
