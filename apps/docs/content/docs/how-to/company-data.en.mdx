```python
from twmarket import Client

with Client() as market:
    statement = market.mops.income_statement("2330", year=2026, quarter=2)
    revenue = market.mops.revenue("2330", year=2026, month=8)
    distribution = market.tdcc.distribution("2330")

for value in statement.rows:
    print(value.account, value.period_end, value.measure, value.value, value.unit)
print(revenue.year, revenue.month, revenue.current, revenue.unit)
for bracket in distribution:
    print(bracket.date, bracket.level, bracket.people, bracket.shares, bracket.percentage)
```

[MOPS](/en/docs/reference/api/mops) · [TDCC](/en/docs/reference/api/tdcc)

## Select data and periods

| Query | Parameters | Result |
| --- | --- | --- |
| `income_statement`, `balance_sheet`, `cash_flow_statement` | Gregorian `year` and `quarter` (1–4) | Statement with account rows |
| `revenue` | `year` and `month` | One `Revenue` |
| `dividends` | Security symbol | Dividend decisions |
| `distribution` | Security symbol | Latest published shareholding brackets |

Supply both period parameters or omit both for the latest statement or revenue record.

## Read results

Select statement values by `account`, `period_end` and `measure`. Each account can have multiple periods or measures. `measure` distinguishes monetary amounts and percentages.

| Revenue field | Meaning |
| --- | --- |
| `current` | Current month's revenue |
| `cumulative` | Cumulative revenue |
| `change_percent` | Percentage change |

Shareholding `level` identifies the source bracket. Level 16 is an adjustment and level 17 is the total. Aggregate the required brackets or read level 17 for the total.

See [models](/en/docs/reference/api/models) for units and missing values.
