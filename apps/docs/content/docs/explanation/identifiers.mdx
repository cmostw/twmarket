各資料來源的識別方式不同，套件保留足以辨認資料的欄位，而不是把所有商品壓成一個代號。

## 證券與公司

上市、上櫃及興櫃證券代號使用字串，保留 `0050` 等前導零。來源 namespace 區分市場；證券目錄另保存 ISIN、分類及上市日期。公司財報、月營收與持股分級以公司或證券代號查詢，回傳欄位仍保留資料自己的期間與來源。

## 期貨與選擇權

契約身分包含商品、到期月份或週別；選擇權還需要履約價與買賣權，價差契約需要兩腿期間。因此商品代碼本身不能唯一識別報價。

有效契約目錄與 `resolve()` 使用官方 metadata 核對 MIS ID，並保存明示到期日。報表代碼與報價代碼可能不同，映射需經官方目錄驗證。價差兩腿保留來源期間，不自行合成 MIS ID 或到期日。規格中的調整契約若未公布個別股數，乘數保留 `None`。

## 經濟系列與幣別

景氣資料以系列與觀測月份識別，不能只按月份合併所有數值。匯率以幣別配對及日期識別；`USD` 篩選可以匹配來源配對的任一側，但不改變配對方向。

## 批次輸入

批次查詢保留輸入順序與重複項目。去除重複網路請求不會去除回傳結果；每筆結果仍對應原請求與個別錯誤。見 [批次查詢](/docs/how-to/query) 與 [模型參考](/docs/reference/api/models)。
