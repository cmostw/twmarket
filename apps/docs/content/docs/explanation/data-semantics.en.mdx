twmarket converts official responses into typed models while preserving source measurement semantics. Matching field names do not make values from different sources directly additive.

## Values and missing data

Prices and monetary values use `Decimal`, avoiding an intermediate binary float during parsing. Missing source values become `None`, distinct from zero. DataFrame conversion preserves `Decimal` by default; selecting floats changes the precision representation.

## Units by domain

| Data | Preserved semantics |
| --- | --- |
| Listed-equity history | Volume in shares; turnover in TWD |
| OTC-equity history | Volume in lots; turnover in thousand TWD |
| Emerging stocks | Daily records and recommending-broker quotes come from different interfaces; interpret each model's fields |
| Futures and options | Volume and open interest in contracts; last trade, close and settlement are separate |
| Financial statements | Account, period and measure are separate; an unspecified source unit is `None` |
| Revenue and dividends | Monetary and percentage values retain source units; percentages are not automatically converted to ratios |
| Shareholding distribution | Brackets, holder counts, share counts and proportions are separate |
| Economic indicators | Numeric values and published signal text are separate and identified by series |
| Exchange rates | Preserve source `numerator`/`denominator` direction without automatic inversion |

## Provenance

`SourceInfo` records the provider, URL and UTC retrieval time. Retrieval time indicates receipt, not a trading date or observation month. Cached records retain their original retrieval time.
