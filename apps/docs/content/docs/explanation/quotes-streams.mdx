股票、興櫃及衍生商品的報價來源和更新方式不同。查詢取得一份來源快照；它不等於完整的成交事件紀錄。

## 查詢報價

TWSE／TPEx 證券報價由 MIS 取得，興櫃報價來自推薦券商資料，期貨與選擇權報價使用 TAIFEX MIS。不同來源有各自的成交、買賣報價與數量欄位；模型保留欄位差異，不將不同用途的價格互相替代。

公司財報、持股分級、景氣指標與匯率則依來源發布頻率更新，並非即時報價。透過相同 client 查詢，不表示資料有相同時效。

## 串流狀態

目前串流介面提供 TAIFEX 報價狀態更新。其他來源的 HTTP 查詢不會自動成為串流訂閱。

完整快照建立狀態；部分更新中未出現的鍵保留原值，明示 `null` 清除欄位。重連、換日或來源切換時，舊快照標為 `stale` 並重建狀態。這些更新描述報價狀態，不承諾包含每筆成交。

## 連線與快取

同步和非同步 client 都管理連線生命週期，非同步串流另管理訂閱。取消或關閉 client 時關閉訂閱。快取可重用一般查詢資料，但即時報價與有效契約查驗略過快取，避免用舊結果判斷目前商品狀態。

使用方式見 [串流操作](/docs/how-to/streaming)，來源封包規格見 [TAIFEX MIS 參考](/docs/reference/taifex-protocol)。
